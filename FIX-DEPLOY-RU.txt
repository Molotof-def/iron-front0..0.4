IRON FRONT 0.5.1 — ИСПРАВЛЕНИЯ СБОРКИ

Что исправлено:
1. @types/react, @types/react-dom и @types/three перенесены в dependencies, чтобы они не пропадали при production-установке пакетов на Render.
2. Удалён некорректный атрибут xmlns из div внутри SVG foreignObject (ошибка TS2322).
3. Node.js закреплён на ветке 22.x через package.json и .nvmrc.
4. Команда сборки в render.yaml использует npm install --include=dev && npm run build.

ВАЖНО: этот архив сам по себе не обновляет GitHub и Render.

Обновление через GitHub Desktop (без команд git):
1. Установить GitHub Desktop: https://desktop.github.com/
2. Войти в GitHub и клонировать репозиторий IRON FRONT.
3. Распаковать этот архив.
4. Открыть папку iron-front внутри архива и скопировать ЕЁ СОДЕРЖИМОЕ в папку клонированного репозитория, заменив файлы проекта.
5. Не удалять локальный .env, если он есть. Не менять переменные окружения Render и не удалять PostgreSQL.
6. В GitHub Desktop проверить список изменений, написать сообщение коммита и нажать Commit to main, затем Push origin.
7. В Render → iron-front → Settings → Build & Deploy установить Build Command:
   npm install --include=dev && npm run build
   Удалить из команды проверку npm ls.
8. Сохранить настройки и запустить Manual Deploy → Deploy latest commit.

Архив содержит .env.example, но не содержит секретных токенов или паролей.

Ограничение проверки: в среде подготовки архива npm registry был недоступен, поэтому полноценные npm build/test здесь не запускались. Исправления выше внесены в исходники, но успешность итоговой сборки должна быть подтверждена логом Render.
